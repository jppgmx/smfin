# Sistema Minimalista para Ficha de Notificação (*smfin*)

O *smfin* é um sistema minimalista desenvolvido para facilitar a criação e gerenciamento de fichas de notificação do SINAN/Ministérico da Saúde. Ele permite que os usuários registrem, visualizem e gerenciem notificações de forma simples e eficiente.
